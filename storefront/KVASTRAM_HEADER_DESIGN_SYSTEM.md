# Odhvica Header Design System

Status: Superseded

This file is intentionally a pointer only. The active storefront design-system source of truth is:

```text
docs/design-system/storefront-design-system-v1.md
```

Current active rules:

- Use `--ds-*` tokens for color, surface, border, typography, radius, spacing, and motion decisions.
- Use TERRACOTTA through `--ds-accent-primary`, `--ds-accent-hover`, `--ds-accent-soft`, and `--ds-accent-rgb`.
- Use the restrained sans commerce typography direction defined in `storefront/src/styles/tokens.css`.
- Header UI should use shared primitives and the tokenized components in `storefront/src/components/header/`.

Do not use older header color, typography, or raw-code examples from previous iterations.
